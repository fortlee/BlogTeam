## Purpose

This file contains writing rules that apply across **ALL your voices**. Think of these as your non-negotiable writing standards that never change, regardless of which specific voice you're using for a particular post.

## When to Use Common Voice vs. Individual Voices

- **Common Voice:** Rules that apply universally (e.g., "never use the word 'umm'", "always cite sources")
- **Individual Voices:** Rules specific to a persona or audience (e.g., technical voice uses jargon, casual voice avoids it)
