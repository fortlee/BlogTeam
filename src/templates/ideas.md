# Ideas

This file is your quick capture space for blog post ideas. When inspiration strikes, just add it here!

## How to Use

1. **Add ideas quickly**: Use any text editor (VS Code, vim, nano, etc.) or edit directly in your git UI
2. **Separate with dashes**: Use four dashes `----` between each idea
3. **No formatting needed**: Just write your raw thoughts - bullets, paragraphs, whatever works
4. **Let the agent present them**: When you run `/blog-team:brainstorm`, the agent will:
   - Show you all captured ideas as a numbered list
   - Let you pick one to develop
   - Analyze if it fits into existing series
   - Make smart recommendations
   - Remove it from this file once you start working on it

## Quick Add Workflow

```bash
# Edit this file
vim ideas.md

# Add your idea at the bottom
# Save and commit
git add ideas.md
git commit -m "Add idea: [your idea]"
git push
```
